# Rin

Windows 上的默认程序管理工具。改文件关联、改协议关联、把「打开方式」自定义。

![主界面](shots/01.png)

## 功能

- **关联管理** —— 列出所有文件类型和协议的默认程序，可搜索、筛选、多选批量修改。
- **应用注册** —— 把一个程序登记成「打开方式」里的选项，或直接设为默认。
- **批量预设** —— 把常用格式存成卡片，一键切换到某个程序，改错了能撤销。
- **备份还原** —— 每次修改前自动备份，随时退回之前的状态。

## 下载

去 [Releases](https://github.com/holdtome/Rin/releases) 下载压缩包。
⚠️ 重要说明：Rin 程序源码不对外开源。项目依赖第三方开源组件，受其开源许可证约束，**无法随安装包 / 压缩包一同集成分发**，请自行前往该开源组件的发布页下载对应文件，放置到指定目录后运行 `Rin.exe`。

## 运行环境

Windows 10 / 11。

## 关于开源

**本项目不开源。** 

仓库只发布编译好的程序和更新说明，不提供源代码。
版权随程序一起分发。

## 注意

这个工具会真实修改系统的文件关联设置。每次操作前都会自动备份，  
改坏了可以在「备份还原」页回退。仍建议先拿不重要的文件类型试一下。
